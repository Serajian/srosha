# ARCHITECTURE

Binding. Read this before writing, editing, or reviewing any Go code in this
repository. Code that contradicts it is wrong, even if it compiles, even if its
tests pass, and even if the surrounding code already does it that way.

**Empty on purpose.** Nothing has been recorded here yet.

This file is written incrementally, from what is actually decided and actually
built — not from a plan drafted in advance. Every entry is proposed to the owner
in full and approved before it is added. Nothing lands here as a side effect of
another task, and nothing is inferred from `docs/reference/srosha-spec-draft.md`,
which is background material and not a decision.

While this file is empty it constrains nothing, and that is the honest state.
A rule that is not written here is not a rule.
