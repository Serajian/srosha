# Summary

Web Push از نقشهٔ راه برداشته شد — **فعلاً**، برخلاف Instagram که برای همیشه رفت.

تنها کانالی بود که به provider ــِ بیرونی وابسته نبود. به تصمیمِ خودمان وابسته
بود: آدرسی که رشته نیست.

# آنچه ماند

آن «تصمیمِ گرفته‌نشده» فقط به‌خاطر Web Push در `ARCHITECTURE.md` بود، و متنش
می‌گفت «تا وقتی Web Push ساخته نشود لازم نیست تصمیمی گرفته شود». پارک کردنِ کانال
یعنی پارک شدنِ سؤال — ولی نه جوابی که همین بررسی تولید کرد.

پس پاراگراف پاک نشد، بازنویسی شد؛ و یک پیامدِ مشخص را ثبت می‌کند که قبلاً نوشته
نشده بود:

```sql
UNIQUE (notification_id, channel, address)
```

اگر subscription به‌صورت json در همان ستون برود، **همان اشتراک با ترتیبِ کلیدِ
متفاوت یک رشتهٔ متفاوت است** و این نگهبان بی‌صدا از کار می‌افتد. نه خطا، نه تستِ
شکسته — فقط یک روز کسی دو بار پیام می‌گیرد.

سه پیامدِ دیگر هم ثبت شد: `ValidateAddress` برای یک کانال تبدیل به json parser
می‌شود، آنچه API به source برمی‌گرداند خواندنی نمی‌ماند، و مادهٔ کلید در ستونی
می‌نشیند که نام نگه می‌دارد.

و شکلی که به‌جایش باید سراغش رفت: جدولِ خودش، با یک id ــِ کوتاه در `address`.
