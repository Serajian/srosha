# Summary

نمونه‌های هر هشت کانال در `sdk/go/README.md` حالا با `go test` کامپایل می‌شوند. دو
تابعِ `Example` تازه در `sdk/go/srosha/example_test.go`، و در README به هم اشاره
دارند. **هیچ کدِ محصولی عوض نشده.**

## مسئله

آن نمونه‌ها امروز صبح نوشته شدند و **دستی** امتحان شدند: یک ماژولِ موقت با
`replace` به همین SDK ساخته شد، هر دو دسته کامپایل شدند، ماژول پاک شد.

آن بررسی واقعی بود و یک بار اتفاق افتاد. دقیقاً همان جنسِ بررسی‌ای که دیگر تکرار
نمی‌شود — و بعدش یک فیلدِ تغییرنام‌داده یا سازنده‌ای که حذف شود، بی‌صدا کهنه‌شان
می‌کند.

و نامِ فیلدِ غلط در مستنداتِ **SDK** بدترین جایش است: خواننده کپی می‌کند و به
کامپایلر می‌خورد، نه به ما.

## راه‌حل، که از قبل در repository بود

`example_test.go` ده تابعِ `Example` دارد و هیچ‌کدام `// Output` ندارند — یعنی
`go test` کامپایلشان می‌کند و اجرا نمی‌کند. دقیقاً همان چیزی که برای یک نمونه‌ای که
به سرورِ واقعی وصل می‌شود لازم است.

دو تابعِ تازه با همان الگو:

```
ExampleCredentials_Register_everyChannel   هر هشت اعتبارنامه
ExampleClient_Submit_everyChannel          هر هشت ارسال، به‌علاوهٔ همه با هم
```

و در godoc هم زیرِ همان متد به‌شکلِ «Example (EveryChannel)» می‌نشینند، پس مستندات
هم هستند نه فقط تست.

## پیوند دوطرفه است

هر دو بخشِ README می‌گویند کدام تابع کامپایلشان می‌کند، و هر دو تابع می‌گویند کدام

این تنها چیزی است که دو فایل را در یک زبان و دو زبان را با هم نگه می‌دارد.
