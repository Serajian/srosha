Branch: `feat/portal-spec`

# Summary

دو چیز از دیدنِ پورتال در مرورگر درآمد، و دومی جدی‌تر از چیزی بود که به نظر
می‌رسید.

## بعد از ورود هیچ راهی به جایی نبود

`/sources`، کلیدها، senderها و callback همه ساخته شده بودند و **هیچ لینکی به
آن‌ها نبود**. مشتری وارد می‌شد، آدرسِ خودش را می‌دید، و گیر می‌کرد. صفحه‌ها را
ساخته بودم و راه رسیدن به آن‌ها را نه.

`layout.html` حالا nav دارد، و طوری زده شده که دوباره جا نیفتد: هر صفحه یک
`chrome` را embed می‌کند و layout از روی همان تصمیم می‌گیرد.

## و همان اصلاح، ورود را شکست

نسخهٔ اولِ `chrome` را فقط به صفحه‌های محافظت‌شده دادم. نتیجه:

```
GET /signin  →  200
             →  ...<div class="form">
                 ← و تمام. نه فرمی، نه </html>
```

`html/template` فیلدی را که وجود ندارد `false` نمی‌گیرد، **خطا می‌دهد**. صفحه
وسطِ تگ می‌ایستد و مرورگر یک ۲۰۰ ناقص می‌گیرد. هیچ‌کس نمی‌توانست وارد شود.

**و لاگ ساکت بود.** gin خطای رندر را در `c.Errors` می‌گذارد و `Abort` می‌کند —
نه panic، نه یک خط لاگ. برای همین از سه بار اجرای دستی و یک prepush سبز رد شد.

سه چیز درست شد: همهٔ صفحه‌ها `chrome` را embed می‌کنند (صفحه‌های ورود مقدارِ صفر
را، که جوابِ درست است)، یک middleware به اسمِ `reportFailures` هرچه gin جمع کرده
را لاگ می‌کند، و تست عوض شد.

## تستی که برای دلیلِ اشتباه سبز شده بود

```go
if strings.Contains(got.body, `class="nav"`) { ... }   // ← این بود
```

nav نبود — **چون صفحه اصلاً به آن‌جا نرسیده بود**. حالا `whole()` بررسی می‌کند
که صفحه واقعاً تمام شده باشد و فرمِ خودش را داشته باشد. امتحانش کردم: باگ را
عمداً برگرداندم و تست شکست با `GET /signin stopped before the end of the page`.

## خوانایی

فهرستِ کانال‌ها خوانده نمی‌شد. رنگ‌ها به‌تنهایی سالم بودند — `#7C93C8` روی
`#040A1C` می‌شود ۶.۴۴:۱ — ولی **کاشی از پشتِ متن رد می‌شد**:

```
روی زمینهٔ صاف   6.44:1
روی خطِ کاشی     4.75:1     و بینشان نوسان
```

یک خطِ ۱۲ پیکسلیِ mono که از روی خطوطِ کاشی می‌گذرد هیچ‌جا عددِ ثابتی ندارد، و
چشم همان لرزش را می‌بیند. این همان قاعده‌ای است که در طراحی نوشته شده بود و CSS
رعایتش نکرده بود: «هیچ الگویی پشتِ متنِ بدنه نیست.» یک scrim اضافه شد که از ۳۸٪
به پایین کاشی را پاک می‌کند؛ بالای پنل که خالی است کاشی می‌ماند. حالا ۶.۴۰:۱،
همه‌جا یکسان.

خطِ جداکنندهٔ بالای فهرست هم `#1A2E63` بود — ۱.۵۲:۱، عملاً نامرئی. شد `--line`.
