# `CONVENTIONS.md` حالا `sdk/` را می‌شناسد

تا امروز فقط `internal/`، `pkg/` و `cmd/` تعریف شده بودند. سه بند اضافه شد، و
بندِ سوم آن تلهٔ واقعی است:

```
go test ./...   وارد ماژولِ تودرتو نمی‌شود
```

پس `make prepush` باید صریح `make sdk` را صدا بزند، و **زبانِ بعدی هم باید به آن
اضافه شود وگرنه هرگز کامپایل نمی‌شود.** بدونِ این بند، کسی که `sdk/python` را
اضافه کند هیچ نشانه‌ای نمی‌بیند که چیزی جا مانده.

و جهتِ وابستگی نوشته شد: **سرور SDK را import می‌کند، هرگز برعکس** — که همان
چیزی است که آن تستِ متقابل را ممکن می‌کند.

## و یک چیزی که یک ابزارِ کوچک پیدا کرد

یک برنامهٔ کوچکِ AST نوشتم که دنبالِ چیزهای صادراتیِ بی‌کامنت بگردد. شش سازندهٔ
`Route` — `Telegram`، `Bale`، `WhatsApp`، `Matrix`، `FCM`، `APNs` — یک کامنتِ
گروهی بالای `Email` داشتند، ولی **godoc آن را فقط به `Email` می‌چسباند**. در
pkg.go.dev بقیه خالی نشان داده می‌شدند.

هرکدام حالا یک خط دارند، و آن خط چیزی می‌گوید که کاربر لازم دارد:

```
Matrix   یک اتاق، و فقط اتاق — این پروتکل «به این شخص بفرست» ندارد
APNs     توکنِ development برای production ناشناس است، و برعکس
```

هجده موردِ باقی‌مانده متدهای interface اند (`Settings`، `String`، `Error`).
کامنت روی هرکدام تکرارِ چیزی است که interface از قبل گفته، و خلافِ قاعدهٔ خودمان
دربارهٔ کامنت‌های کم و کوتاه.
