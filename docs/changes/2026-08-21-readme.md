# readme — نوشتن README با هویت برند

## چی خواسته شد

README ریپو نوشته شود؛ دقیق و واضح و تمیز، با تصویر hero برند در بالای صفحه.

## چی شد

- `README.md` از صفر نوشته شد: hero بالای صفحه، سه badge، معرفی کوتاه سرویس و
  معنای اسم، دیاگرام معماری، جدول دو binary، شروعِ کار local با make،
  ساختار پوشه‌ها، وضعیت فعلی پروژه (صادقانه: در حال توسعه)، و لینک مستندات.
- یک دیاگرام SVG جدید ساخته شد: `docs/assets/brand/architecture.svg` —
  مسیر request از client تا چهار کانال، با پالت برند.
- مسیر دیاگرام در `docs/CONFIG.md` بخش «Brand assets» ثبت شد.

## چرا این‌طوری

- محتوای README فقط از چیزهایی نوشته شد که واقعاً در ریپو هست؛ `migrations/`
  و API چون هنوز ساخته نشده‌اند، فقط در بخش Status آمده‌اند، نه در دستورها.
- دیاگرام SVG است تا در ریپو قابل ویرایش بماند و در dark/light گیت‌هاب درست
  دیده شود (زمینه‌ی سرمه‌ای خودش را دارد).

## چی جا ماند

- بخش License نوشته نشد چون ریپو هنوز فایل LICENSE ندارد.
