# Summary

بخشِ ۲ از README ــِ SDK (هر دو زبان) دنیایی را توصیف می‌کرد که دیگر وجود ندارد.
می‌گفت srosha نه admin API دارد نه console، و کلید را باید بیرون از سرویس از
اپراتور گرفت؛ بعد هم زیرِ یک `<details>` دو دستورِ `INSERT` می‌گذاشت که خودِ
اپراتور با آن‌ها `sources` و `api_keys` را دستی می‌ساخت. آن متن برچسبِ «موقتی»
داشت و شرطش این بود که پنلِ مدیریت ساخته شود. پنل ساخته شد.

جای آن، مسیرِ واقعیِ امروز نوشته شد؛ هر قدمش از کد بیرون آمده نه از حافظه:

- ورود با ایمیل و کدِ شش‌رقمی — `logincode`.`digits` برابرِ ۶ است، و
  `usecase.SignIn.find` برای آدرسی که تا حالا نیامده همان‌جا یک user با نقشِ
  `RoleCustomer` می‌سازد. یعنی ثبت‌نامِ جدا واقعاً وجود ندارد.
- ساختِ source از portal با `usecase.Sources.Register`. `source.New` آن را با
  `IsActive: false` و `AllowCustomAddress: false` و `MaxPriority` برابرِ
  `NORMAL` برمی‌گرداند.
- تأییدِ operator. `source.Approve` اول `IsReachable()` را می‌پرسد، پس نوشته شد
  که source ــِ بی‌آدرس اصلاً روشن نمی‌شود.
- صدورِ کلید توسطِ خودِ مشتری در `web.keyHandler.issue`. قالبِ کلید از
  `adapter/auth/const.go` آمد: `prefix` برابرِ `srosha_` و `bodyLen` برابرِ ۴۳.

یک جمله هم اضافه شد که چرا در دورهٔ انتظار `ErrForbidden` می‌گیرید و نه
`ErrUnauthorized`: `source.EnsureActive` عمداً `ForbiddenErr` برمی‌گرداند تا
«source خاموش است» از «کلید غلط است» قابلِ تشخیص باشد.

ادعای «یک source می‌تواند **دو** کلید داشته باشد» به «بیش از یک کلید» تغییر کرد.
هیچ‌جای کد چنین سقفی ندارد؛ عددِ دو فقط در کامنتِ migration ــِ `00004` به‌عنوانِ
دلیلِ جدا بودنِ جدول آمده بود، نه به‌عنوانِ محدودیت.

آن `<details>` حذف نشد، کوچک شد: حالا فقط دو فیلدی را توضیح می‌دهد که پنل
نشان‌شان می‌دهد ولی هنوز ویرایش‌شان نمی‌کند — `max_priority` و
`allow_custom_address` — با یک `UPDATE` به‌جای دو `INSERT`. این را از
`public/templates/admin/source.html` تأیید کردم: هر دو رندر می‌شوند و هیچ فرمی
برایشان نیست.

در همان فایل یک ادعای غلطِ دیگر هم درست شد: بخشِ نصب می‌گفت «Go 1.23 به بالا»،
در حالی که `sdk/go/go.mod` از همان v0.1.0 روی `go 1.25.0` بوده. کسی روی ۱٫۲۴
به آن اعتماد می‌کرد و build نمی‌شد.

هیچ کدِ Go ای عوض نشده. این commit فقط متن است.
