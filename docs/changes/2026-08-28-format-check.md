# ۱ — `golines` در `prepush` نبود

```
make format    gofmt + gci + golines
make prepush   gofmt          ← golines نبود
```

یعنی کدِ بلند می‌توانست commit شود و **هیچ چیز نمی‌گرفتش** — تا روزی که کسی
`make format` بزند و یک diff ــِ بی‌ربط لای کارش پیدا کند.

که دقیقاً همان اتفاقی بود که افتاد: ۳۵ فایل جمع شده بودند، و سرِ قدمِ اولِ SDK
بیرون زدند.

`golines` یک `-l` دارد، مثل `gofmt`. حالا در `fmt-check` است.

**و ثابت شد که همان شکاف را می‌بندد** — فایلی ساخته شد که gofmt کاملاً از آن
راضی است:

```
🔎 gofmt -l...     چیزی نگفت
🔎 golines -l...   ❌ lines over 100: internal/toolong.go
```

## و یک شکافِ دومِ همان‌جا

`fmt-check` فقط `./cmd ./internal ./pkg` را نگاه می‌کند و **`sdk/` را نمی‌بیند**.
آنجا `golangci-lint` در `make sdk` پوششش می‌دهد — ولی این بدیهی نیست و نوشته
نشده بود، پس در کامنتِ هدف نوشته شد. کسی که `sdk/python` اضافه کند باید بداند
کدام بررسی کجاست.
