# brand-assets — لوگو و هویت بصری

## چی خواسته شد

برای سرویس لوگو و تصویر برند طراحی شود. بعد از چهار دور طرح پیشنهادی، مدل «اوریگامی»
(درنای کاغذی — نامه‌ای که تا خورده و پرنده شده) انتخاب و تأیید شد.

## چی شد

- فایل‌های برند در `docs/assets/brand/` گذاشته شد:
  - `srosha-logo.svg` — نسخه‌ی vector اصلی (trace شده از تصویر مرجع تولیدشده)
  - `srosha-16/32/64/256/512.png` — خروجی PNG برای favicon و آواتار
  - `srosha-mono-512.png` و `srosha-mono-white-512.png` — نسخه‌های تک‌رنگ
  - `srosha-hero.png` — تصویر ۱۲۸۰×۴۰۰ برای بالای README
- پالت رنگ و مسیر فایل‌ها در `docs/CONFIG.md` بخش «Brand assets» ثبت شد.
- فونت wordmark: فونت Onest از Google Fonts با وزن ۷۰۰.

## چرا این‌طوری

- طرح‌های دستی اولیه کیفیت لازم را نداشتند؛ نسخه‌ی نهایی از یک تصویر مرجعِ تولیدشده
  با ابزار vtracer به vector تبدیل شد تا فرم دقیق بماند.
- رنگ‌های پالت از خود لوگو استخراج شده‌اند، نه دستی.

## چی جا ماند

- README هنوز از تصویر hero استفاده نمی‌کند؛ اضافه‌کردنش یک تغییر جداست.
- favicon.ico ساخته نشد — PNGها کافی بودند و اگر لازم شد از همین‌ها ساخته می‌شود.
